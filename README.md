**ФИО:** Бигулов Александр Артурович

**Тема проекта:** Разработка сайта (CRM) для медицинского центра

## Описание

Проект представляет собой self-hosted CRM систему для медицинских клиник, созданную с использованием семантической HTML-разметки и современных CSS стилей. Система предназначена для администрации клиники, регистратуры и врачей для управления пациентами, записями на прием, расписанием и отчетностью.

## Функциональность системы

### Авторизация и роли

- **Система авторизации** - вход по логину/паролю с поддержкой различных ролей
- **Роли пользователей:**
  - Врач - ведение медицинских записей, доступ к своему расписанию
  - Администратор - управление записями, расписанием, финансами, складом
  - Руководитель - полный доступ ко всем функциям системы
  - Системный администратор - настройки системы, управление пользователями

### Основные модули

#### Панель управления (Dashboard)

- Роль-зависимое отображение информации
- Для врача: список записей на сегодня
- Для администратора: онлайн-записи, быстрые действия
- Для руководителя: KPI и аналитика

#### Расписание

- Просмотр записей по филиалам и датам
- Фильтрация и поиск
- Отображение статусов записей
- Переход к детальной информации о записи

#### Управление пациентами

- Поиск пациентов по ФИО и телефону
- Создание новых пациентов
- Просмотр карточек пациентов
- История визитов пациента

#### Записи на прием

- Создание новых записей
- Привязка к пациентам
- Выбор услуг и врачей
- Управление статусами записей

#### Карточка записи

- Детальная информация о записи
- Управление статусами (для администратора)
- Блок оплаты (для администратора/руководителя)
- Медицинская запись (для врача)
- История изменений

### Технические особенности

#### Frontend технологии

- **Семантическая HTML-разметка** - использование правильных HTML5 тегов
- **Современный CSS** - Grid, Flexbox, CSS переменные
- **Адаптивный дизайн** - медиа-запросы для мобильных устройств
- **Анимации и переходы** - улучшение UX

#### JavaScript и API

- **Fetch API** - для выполнения HTTP-запросов
- **Promise и async/await** - асинхронная работа с API
- **Обработка ошибок** - корректная обработка сетевых ошибок, ошибок сервера, 404, 401, 403
- **Прелоадеры** - отображение состояния загрузки
- **Шаблоны в HTML** - использование `<template>` для динамического контента
- **Фильтрация данных** - применение различных фильтров при каждом запросе

#### Интеграция с API

- **REST API** - интеграция с внешним API (my-json-server.typicode.com)
- **Fallback на локальные данные** - использование локального mock_api.json при недоступности API
- **Авторизация** - Bearer token authentication
- **Обработка ответов** - корректная обработка различных статусов ответов

#### Архитектура

- **Модульная структура** - разделение кода на отдельные модули
- **Централизованное управление API** - единая точка входа для всех запросов
- **Утилиты** - переиспользуемые функции для работы с API, прелоадерами, ошибками

## Использование

### Важно: Запуск локального веб-сервера

**Приложение не будет работать при открытии HTML файлов напрямую через `file://` протокол** из-за ограничений безопасности браузера (CORS policy). Необходимо использовать локальный веб-сервер.

#### Быстрый запуск

**Windows:**

```bash
start-server.bat
```

**Linux/Mac:**

```bash
chmod +x start-server.sh
./start-server.sh
```

#### Ручной запуск

Выберите один из способов:

1. **Python 3:**

   ```bash
   python -m http.server 8000
   ```

   или

   ```bash
   python3 -m http.server 8000
   ```

2. **Node.js (требуется установка http-server):**

   ```bash
   npx http-server -p 8000
   ```

3. **PHP:**
   ```bash
   php -S localhost:8000
   ```

После запуска сервера откройте в браузере:

- **http://localhost:8000/login.html**

### Вход в систему

1. Откройте `http://localhost:8000/login.html` в браузере
2. Войдите в систему используя тестовые данные:
   - Логин: "Ирина Петрова" или "1" (Администратор)
   - Логин: "Доктор Иванов" или "2" (Врач)
3. После входа вы будете перенаправлены на панель управления
4. Используйте навигацию для перехода между разделами

## API

Система использует внешний API:

- **Базовый URL:** `https://my-json-server.typicode.com/bialger/mis-mock-data/`
- При недоступности внешнего API используется локальный файл `api_data/mock_api.json`

## Требования

- Современный браузер с поддержкой ES6+
- Локальный веб-сервер (Python 3, Node.js с http-server, или PHP)
- Подключение к интернету для работы с внешним API (опционально)

### Установка зависимостей (опционально)

Если используете Node.js:

```bash
npm install -g http-server
```
