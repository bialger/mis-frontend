**Тема проекта:** Разработка сайта (CRM) для медицинского центра

## Описание
Проект представляет собой self-hosted CRM систему для медицинских клиник, созданную с использованием семантической HTML-разметки и современных CSS стилей. Система предназначена для администрации клиники, регистратуры и врачей для управления пациентами, записями на прием, расписанием и отчетностью.

## Макет системы
![Макет системы](design.png)

Доступны следующие разделы:
- **Header** - навигационное меню с основными модулями системы
- **Main** - основное содержимое:
  - Dashboard - панель управления системой
  - Patients - управление пациентами и их данными
  - Doctors - управление штатом врачей
  - Schedule - планирование и календарь записей
  - Reports - отчеты и аналитика
  - Aside с уведомлениями системы
- **Footer** - системная информация и статус

## Функциональность CRM системы
Система включает следующие модули:
- **Управление пациентами** - регистрация, редактирование данных, история обращений
- **Управление врачами** - штат врачей, специализации, расписание
- **Планирование** - календарь записей, управление кабинетами
- **Отчетность** - статистика работы, аналитика, финансовые отчеты
- **Уведомления** - системные сообщения и напоминания

### Технические особенности:

- **Современная CSS Grid и Flexbox** - заменено табличное форматирование на современные CSS технологии
- **CSS переменные** - централизованное управление цветовой схемой
- **Адаптивный дизайн** - медиа-запросы для мобильных устройств
- **Анимации и переходы** - hover-эффекты для улучшения UX
- **Семантическая разметка** - использование правильных HTML5 тегов
- **Доступность** - alt-атрибуты для изображений, правильная структура заголовков
